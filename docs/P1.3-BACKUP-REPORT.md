## 2. bundle 包含什么

bundle 包含当前 Git 历史中的全部受版本控制文件：

- `src/`：React + TypeScript 前端、Canvas 场景、Graph Projection、中文解释层、理解检查；
- `tools/`：Graphify 转换、场景/解释附加、构建门禁、P1.2/P1.3 浏览器验收、性能、录屏、备份审计；

- `docs/`：P0–P1.3 报告、Schema、模块证据、截图、录屏、验证/性能 JSON；
- `package.json` / `package-lock.json` / `tsconfig` / `vite.config.ts`；
- 字体与许可证文件。

bundle 不是“运行中的项目目录”，而是可克隆的 Git 历史；克隆后仍需 `npm ci` 与 `local-data`。
