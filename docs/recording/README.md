## P1.2 真实架构投影

| 文件 | 说明 |
| --- | --- |
| `dachuan-atlas-p12-demo.mp4` | 1440×810，H.264，30 FPS，50.6 秒，无音轨 |
| `dachuan-atlas-p12-demo.webm` | 1440×810，VP9，30 FPS，同一录制 |
| `P1.2-RECORDING.json` | 帧数、采集帧率、时长与文件说明 |

- **演示路径**：本地快照导入 → NEXUS 真实跨模块连线 → 架构投影模块 / 文件 / 符号 → 路径查询 → 模块中文关系 → 按流程理解与图谱缺口 → 演示模式回归。

- **演示层**：录制时注入的底部步骤说明与光标环仅用于观看，不属于产品界面。真实数据只从本地 `.atlas.json` 导入，未上传。
- **数据边界**：演示中的连线和证据来自本地历史快照；橙色中枢连接、星点、轨道与流星仍是构图装饰。
- 录屏无声音。
